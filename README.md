# ききごこち — 聞き心地で採点するボイトレ・カラオケ

採点機種の「攻略」ではなく、**誰が聞いても上手いと感じる歌**ほど高得点になるように設計した、iPhone 向けのカラオケ採点 Web アプリです。
点数はモチベーション用。本当の目的は、ボイトレの先生のように「どこが聞き心地を損ねていて、何を練習すればいいか」を教えることです。

- 歌声だけで採点（伴奏・メロディデータ不要）。録音・解析はすべて端末内で完結し、音声は外部に送信しません
- iPhone + イヤホンマイク（EarPods など）で使う想定。Safari で開いて「ホーム画面に追加」するとアプリのように使えます

## 何を評価するか

| 項目 | 見ているもの |
|---|---|
| 音程の正確さ | 1 音ごとの半音グリッドからのズレ（歌い手自身の基準に対して）、キー外の音、曲中のずれ込み |
| 声の安定感 | ロングトーンの揺れ・途中での下がり・音量の揺れ（ビブラートは除外） |
| 声の響き・質 | 明瞭度（倍音と雑音の比 = 息漏れ・かすれ）、2〜4kHz の響き（こもり／キンキン） |
| 音の入り・つなぎ | しゃくりの頻度と長さ、跳躍時のずり上げ・行き過ぎ |
| 抑揚・音量コントロール | フレーズ内外の強弱、意図しない音量の急変 |
| フレーズの終わり方 | 語尾の音程落ち |
| ビブラート・余韻 | 速さ（5〜7 回/秒が心地よい）・深さ・規則性。ちりめん／うねりを検出 |
| 高音の余裕 | 高音域での声質低下・ぶら下がり・張り上げ |
| メロディ・リズム（任意） | 「お手本ボーカル」登録時のみ。メロディ違い、もたり・走り |

総合点は **重み付きのべき平均（p = −2）** で、苦手項目が 1 つでもあると強く下がります（耳障りな要素は 1 つでも聞き心地を大きく損なうため）。

結果画面では：先生のコメント、良かったところ、改善ポイント（該当箇所をタップで再生）、タイムライン、今日の練習メニュー、次回の目標を表示します。

## iPhone で使う（公開方法）

マイクを使うため **HTTPS で配信** する必要があります。いちばん簡単なのは GitHub Pages です。

1. このフォルダを GitHub リポジトリとして push
2. GitHub のリポジトリ → Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` に
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPhone の Safari で開く
4. 共有ボタン → 「ホーム画面に追加」

ビルド不要（素の ES Modules）なので、ファイルを置くだけで動きます。Netlify / Cloudflare Pages などの静的ホスティングでも OK。

## 開発

```bash
# 開発サーバ（キャッシュ無効） http://localhost:8765
python tools/devserver.py

# 回帰テスト（合成歌声で採点ロジックを検証）
node tests/run-all.mjs
```

PC のブラウザでも動作します（マイク or 音声ファイル）。

### 構成

```
js/
  dsp/fft.js, frameAnalyzer.js   … 16kHz・10ms ごとのピッチ（McLeod Pitch Method）・明瞭度・音量・スペクトル特徴
  analysis/analyze.js            … 音符分割、音程ズレ、安定、ビブラート、しゃくり、語尾、抑揚、声質、高音
  analysis/score.js              … 計測値 → 項目スコア → 総合点（しきい値は CALIB に集約）
  analysis/coach.js              … 先生のコメント・改善ポイント・練習メニュー
  analysis/compare.js            … お手本との比較（DTW による整列、移調推定、メロディ違い・タイミング）
  worker.js                      … 解析ワーカー（録音中にストリーミング解析）
  audio/                         … マイク入力（AudioWorklet）、録音、再生、伴奏
  views/, ui/                    … 画面
tests/                           … 合成歌声ジェネレータと回帰テスト
```

### 採点の調整（キャリブレーション）

しきい値はすべて `js/analysis/score.js` の `CALIB` にあります。
結果画面の「詳細データ（上級者・調整用）」に生の計測値が出るので、

1. プロ歌手のボーカルだけの音源（アカペラ）を「録音済みの音声を採点」で読み込む
2. 詳細データの値を見て、プロが 95〜100 に入るよう `CALIB` の区間を調整
3. `node tests/run-all.mjs` で回帰テストが通ることを確認

という流れで実データに合わせ込めます。

## わかること・わからないこと

- ✓ 音程の正確さ、声の安定、しゃくり、語尾、ビブラート、抑揚、高音での力み、声のかすれ・こもり
- △ メロディの正しさ・リズム：お手本ボーカル（原曲から抽出したボーカル等）を登録した曲のみ
- ✗ 歌詞の正しさ
